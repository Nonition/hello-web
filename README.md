# hello-web

One static page. One word.

Open it in a sandbox by swapping the hostname:

```
https://github.com/hyuki36/hello-web
https://githubbox.com/hyuki36/hello-web
```

## Files

| file | purpose |
| --- | --- |
| `index.html` | the page |
| `styles.css` | warm bone/ink/ember palette, fluid type |

No build step, no dependencies. Any static server works:

```
npx serve .
```
